## What changed

Modified in November 2026:

- Renamed the project, command and package to CloneX.
- Restructured the code into separate read-only planning and execution.
- Reduced the Discord requests a copy needs by ordering channels in bulk.
- Added a settings file for choosing what is copied and replaced.
- Added translations of the interface and automatic language detection.
- Added standalone builds and installers for macOS, Linux and Windows.
- Added an offline test suite and continuous integration.
